# Introduction

[uses.tech](https://uses.tech) is a community-curated directory of `/uses` pages. Thousands of developers from around the world have published entries listing the exact hardware, software, editors, themes, fonts, and tools they use every day — and you can browse all of them in one place.

The project is open source, maintained by [Wes Bos](https://wesbos.com) (whose own `/uses` page is at [wesbos.com/uses](https://wesbos.com/uses)), and lives at [github.com/wesbos/awesome-uses](https://github.com/wesbos/awesome-uses). The entire directory is a single `data.js` file — anyone can add their page by submitting a pull request.

## What the directory covers

Each entry in the directory describes one developer's setup. Across the thousands of entries you'll find:

- **Hardware** — computers (Apple, Windows, Linux, BSD), phones (iPhone, Android), peripherals
- **Software** — code editors, terminals, browsers, productivity apps
- **Configuration** — themes, fonts, keybindings, dotfiles
- **Tools and frameworks** — languages, libraries, DevOps tooling, design software

The site lets you filter by technology tag (JavaScript, TypeScript, React, Vim, Docker, and hundreds more), by country, and by device type.

<Note>
  uses.tech is fully open source under the [wesbos/awesome-uses](https://github.com/wesbos/awesome-uses) repository. Contributions are made through pull requests — there is no admin approval process beyond automated validation and maintainer review.
</Note>
